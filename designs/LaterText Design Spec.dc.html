DESIGN ASSUMPTIONS
· SMS/MMS send permission is grantable (private / enterprise distribution); LaterText is never the default SMS app and has no inbox.
· One-to-one messages only; a “schedule” = one recipient + content + timing rule. Recurring sends reuse the same content.
· Jitter offsets are sampled once per occurrence at scheduling time and persisted; previews show the sampled result.
· RCS is assisted-only: a notification opens the default messaging app with content prefilled; the user taps Send there.
· “Sent to carrier” ≠ “Delivered”; delivery receipts are best-effort and may stay “Unknown”. Copy never promises delivery.
· Contact access uses the Android system Contact Picker (no in-app contact database); numbers can also be typed manually.
· GIFs come from GIPHY and are downloaded locally on save; sends never depend on the GIPHY API being reachable.
· Without exact-alarm access the app still works, labeled “Approximate timing” (±10 min OS batching).
· Carrier-safe MMS budget assumed 1 MB; larger media is auto-compressed with user notice.
· Dual-SIM is supported; SIM choice is per-schedule with an app-level default.

Layout rules on show / hide
KEYBOARD SHOWS ↑
· Window resizes (never pans): edge-to-edge + IME insets, no adjustPan
· App bar collapses 56→44dp; recipient chip row pins at top
· Message card shrinks; inner scroll keeps the cursor line above the IME at all times
· Edit bar (attach · counter · transport · Schedule) docks flush above the keyboard and translates 1:1 with it
· Bottom nav + FAB sit under the IME — excluded from the resized layout, no double padding
KEYBOARD HIDES ↓
· Same synchronized animation in reverse; scroll position and cursor preserved
· Edit bar expands back into the full action row (Send now + Schedule) once insets reach 0
· Drag-to-dismiss: scrolling the message body down drags the IME away with the gesture (imeNestedScroll)
· In sheets (schedule editor, GIF search): the sheet rises with the IME; on hide it settles back to its anchor — content inside never reflows mid-animation
